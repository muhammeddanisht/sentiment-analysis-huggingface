# Sentiment Analysis using HuggingFace

Built a sentiment analysis system using HuggingFace Transformers and DistilBERT pretrained model.

## What I Built
- Loaded pretrained DistilBERT model using HuggingFace pipeline
- Classified sentences as POSITIVE or NEGATIVE with confidence scores
- Tested on multiple real sentences

## Results
- "I love to travel" → POSITIVE (99.98%)
- "I hate being stuck at home" → NEGATIVE (93.58%)
- "Switzerland is my dream destination" → POSITIVE (99.98%)
- "I will achieve financial independence" → POSITIVE (99.94%)

## Tech Stack
- Python
- HuggingFace Transformers
- DistilBERT pretrained model
- Jupyter Notebook

## Why This Matters
This project demonstrates using industry-standard pretrained models for real NLP tasks — the same approach used by companies building production AI systems.
